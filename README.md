# Coptic Alphabet Lessons

A slideshow website for teaching the Coptic alphabet: 4 lessons, 92 slides. Words and answers appear one click at a time, and a **Download PowerPoint** button makes a .pptx copy of the current slides.

- **To change or add slides, edit `slides.js`.** [EDITING.md](EDITING.md) walks through it, with a copy-paste example for every kind of slide.
- **Presenting:** → or Space for next (or click the slide), ← to go back, **M** for the lesson menu, **F** for full screen.
- **No internet?** Copy the whole folder to a flash drive and open `index.html`. The slides and the Coptic font work offline. The PowerPoint button needs the website.

## Files

| File | What it is |
|---|---|
| `slides.js` | All the slide content. **The only file you edit.** |
| `index.html` | The page itself |
| `assets/` | The design (backgrounds, letter pictures, fonts) and the slideshow code |
| `EDITING.md` | How to edit the slides |
